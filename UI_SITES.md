### How to Use Installed Skills in Conversation

#### 1. Frontend Design (`/frontend-design`)
- **How to Use**:
  1. Trigger with `/frontend-design` or declare an aesthetic direction upfront (e.g. "Build an editorial countdown timer", "Create a brutalist merch grid").
  2. The agent commits to typography hierarchies, spacing scales, and CSS variable tokens before coding.
  3. Eliminates all AI slop: no generic Inter-only layouts, no cliché purple gradients, no cookie-cutter cards.
  4. Produces production-ready React components with cohesive tactile physics.
- **Example Prompt**:
  > *"Design an editorial music release countdown with oversized serif numeral counters, stark black-and-white contrast, hairline borders, and subtle vinyl groove textures using Frontend Design principles."*

#### 2. Unslop (`/unslop`)
- **How to Use**:
  1. Ask the agent to `/unslop` or run a redline review on any component, screen, or viewport.
  2. The agent executes the 9-pass checklist: Spacing, Color, Icons, Copy, Type, Layout, Details, Visuals, Motion.
  3. Strips away emoji buttons, glowing blobs, uppercase tracked pills, and battery-draining animations.
  4. Replaces them with crisp Lucide icons, solid tactile controls, and high-contrast readable typography.
- **Example Prompt**:
  > *"Unslop the mobile audio player sheet: eliminate glowing purple blobs, replace emoji buttons with crisp Lucide icons, tighten the spacing rhythm, and remove continuous ping animations."*

#### 3. GitHub Spec-Kit (`/speckit.specify`)
- **How to Use**:
  1. Run `/speckit.specify <feature idea>` in chat to draft a structured specification.
  2. Review and refine the generated `spec.md` artifact in the `.specify/` directory.
  3. Execute `/speckit.plan` to produce a technical architecture and dependency breakdown.
  4. Run `/speckit.tasks` to generate sequenced, bite-sized tasks.
  5. Execute `/speckit.implement` to methodically execute against tasks.
- **Example Prompt**:
  > *"/speckit.specify Build a VIP Fan Portal with exclusive audio stems, passwordless magic links, and download quotas."*

#### 4. Appllama Mobile Design (`/appllama`)
- **How to Use**:
  1. Connect Appllama MCP at `https://mcp.appllama.io/mcp`.
  2. Benchmark against top-grossing apps: "Study the onboarding flows of top audio and music apps."
  3. Extract layout skeletons, spacing rhythms, and paywall timing.
  4. Build native React Native / Expo screens with Apple HIG fidelity and Reanimated 60fps springs.
- **Example Prompt**:
  > *"Use the Appllama MCP to study the onboarding flows and paywall placement of the top 5 meditation and habit apps."*

#### 5. Supabase & Postgres (`Supabase MCP`)
- **How to Use**:
  1. Direct the agent to read, write, or migrate database state on `unnoticed-website`.
  2. Uses Supabase MCP tools (`execute_sql`, `list_tables`, `apply_migration`, `query_logs`).
  3. Verifies RLS security policies so anonymous visitors have read-only access while mutations require credentials.
  4. Syncs changes instantly across web, mobile, and admin interfaces.
- **Example Prompt**:
  > *"Audit the Row Level Security (RLS) policies on public.site_data: confirm that public anonymous reads are enabled while mutations require service role or admin credentials."*
